# Bank Account Manager

Bank Account Manager is a simple Java project developed to practise object-oriented programming, exception handling, input validation, and unit testing with JUnit 5.

## Features

- Create a bank account.
- Check the account balance.
- Deposit money into an account.
- Withdraw money from an account.
- Validate deposit and withdrawal amounts.
- Handle insufficient funds using a custom exception.

## Technologies Used

- Java
- Maven
- JUnit 5
